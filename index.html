Local Edition

Built to run your gym. Right where your gym operates.

HyMotion Local Edition runs on a gym server on the local network. Staff devices share one gym database — and normal daily operation does not require the internet.

Gym serverA PC or server inside the gym
HyMotion LocalThe system the staff uses
SQL database · local

Owner Dashboard · management

HR Staff · employee management
Internet is not required for normal local operation
Runs locally HyMotion Local is installed and runs inside the gym — it is not a browser tab to a far-away cloud.
The gym's own network Multiple staff devices — reception PC, owner laptop, desk tablet — reach the same system over the local network.
Local SQL database The gym's data lives in a proper SQL database on the gym's own hardware — with backup and recovery built in.
Backup & recovery Automatic database backups and one-step restore — because gym data is the gym's, and it must survive anything.
