HyMotion Local Edition

Built to run your gym. Right where your gym operates.

HyMotion Local Edition is installed in the gym, runs on the gym's own network, and keeps the gym's data in a local SQL database. The staff works from multiple devices — the data stays in one place.

Setup

From boxes to running — in three steps.

1
HyMotion Local is set up on a gym machine
  • A PC or server inside the gym runs the system and its local SQL database
2
Staff devices connect over the gym network
  • Reception PC, owner laptop, or desk tablet — any device on the network reaches the same system in the browser
3
Each staff member logs in with their role
  • Owner, reception, trainer, and HR each see the desks their permissions allow — one database, zero conflicts

What that means

Local-first, on purpose.

Runs locally Installed inside the gym — not a tab pointing at someone else's cloud.
Works on the gym's network Multiple staff devices access the same gym data at the same time.
Local SQL database Proper database engine on the gym's own hardware — built for real operational data.
No internet required Normal daily operation is fully local. The gym doesn't stop when the line drops.
Backup & recovery Automatic backups of the gym database, and a restore path when you need one.
Permission-based access Owner, reception, trainer, and HR use the system according to their roles.

Backup & recovery

The gym's data belongs to the gym.

Local Edition treats gym data like an asset: automatic backups, a restore path, and the database physically on the gym's hardware. Not held hostage anywhere.

  • ✓Automatic scheduled backups
  • ✓Manual back-up at any moment
  • ✓Restore path when it's needed
